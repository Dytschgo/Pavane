## Recovery contracts

**Try again** applies only to the latest unfinished attempt per model for the most recent user turn. Earlier complete replies remain immutable. The native boundary resolves the original chat/message and model; caller-provided replacement content/models cannot redirect a retry. Existing provider validation/authorization/key snapshots, queue limit, cancellation tokens and streaming path apply. A missing model opens its own provider setup without silently switching providers. Ordinary Connections starts at the selected model’s provider; users can select any other provider from the flat list.

The storage operation uses an immediate transaction to revalidate eligibility and append one assistant/run. It preserves the original failed partial, original user message, chat title/retention and unsent draft. It adds no duplicate user message. Active chats, complete replies, superseded attempts, older turns, wrong-chat IDs, user-message IDs and expired chats are rejected. Exclusive database ownership remains enforced. No migration is introduced. Retry uses current saved workspace instructions and the model's current supported options; historical option snapshots were not persisted and are not invented. Provider-side charges and success are not guaranteed by retry.

**Recheck connections** reruns provider discovery with the existing native paths. It leaves saved setup and unsent draft intact, disables while checking and reports a plain failure with the same action available again. It does not install a CLI, sign in, replace a key or send a chat request. Successful discovery does not prove live inference.

**Retry save** re-enqueues the latest cached draft snapshot using the existing coalescing writer. Failure feedback is associated with its chat. It clears only after the latest snapshot is acknowledged or a normal send durably accepts that draft as the prompt. Navigation retains cached text. An oversized draft cannot be retried until it fits. Failed storage cannot be repaired by pretending the save succeeded.
